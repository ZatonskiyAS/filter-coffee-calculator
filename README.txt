FILTER COFFEE - публикация на iPhone

В папке находятся:
- index.html: приложение
- manifest.webmanifest: параметры установки как PWA
- sw.js: офлайн-кэш

Чтобы открыть по интернет-ссылке, загрузите эти три файла в корень статического сайта (например, GitHub Pages или Netlify).
После публикации откройте HTTPS-ссылку в Safari на iPhone:
Поделиться -> На экран «Домой» -> Добавить.

Важно: само создание файлов не публикует сайт в интернете. Для постоянной публичной ссылки нужен хостинг.
