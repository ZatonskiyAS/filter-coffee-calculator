FILTER COFFEE 4.3.1 - файлы приложения

В архиве находятся:
- index.html - калькулятор и обучающие материалы;
- manifest.webmanifest - параметры установки приложения;
- sw.js - офлайн-кэш;
- README.txt - эта инструкция.

Публикация:
1. Распакуйте архив.
2. Загрузите все четыре файла в корень репозитория GitHub Pages, заменив предыдущие версии.
3. Создайте коммит в ветке main.
4. Дождитесь завершения публикации GitHub Pages.

Для установки на iPhone откройте опубликованный HTTPS-адрес в Safari, нажмите «Поделиться», затем «На экран Домой».
